# AGENTS.md

Для разработки EffectiveTube использовались следующие подходы и агенты:

1.  **Роль:** ИИ (OpenCode, модели Gemini/Claude; ранние итерации — Claude 3.5 Sonnet)
    выступал как основной разработчик кода, инженер — как архитектор и ревьюер.
2.  **Декомпозиция:** Проект был разделен на независимые модули (API, DB, Worker,
    Storage), что позволило минимизировать количество конфликтов в коде при
    итеративной разработке.
3.  **Правила работы:**
    *   Асинхронность везде (SQLAlchemy 2.0).
    *   Строгая типизация (Pydantic v2).
    *   Безопасность (CSRF, CSP).
    *   Вся авторизация — через `app/services/access.py`.
    *   Изменения схемы БД — только миграциями Alembic.
    *   Сначала тест/ручной сценарий, потом «готово».
4.  **История:** История разработки зафиксирована в коммитах git. Экспортированные
    сессии ИИ лежат в `ai-dialogs/` в исходном JSON (как есть), описание процесса —
    в `docs/ai-workflow.md`.
