# Разработка EffectiveTube

## Локальная проверка

```bash
make install
make test
make lint
```

Интеграционные тесты запускаются против поднятого Docker-стека:

```bash
make up
make test-integration
```

## Правила изменений

* изменения схемы БД оформляются Alembic-миграцией;
* авторизация и ACL остаются в `app/services/access.py` и зависимостях;
* критичные сценарии сопровождаются тестом;
* коммиты должны описывать один законченный этап работы.
